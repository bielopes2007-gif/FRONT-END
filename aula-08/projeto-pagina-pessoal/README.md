## Apresentação

Curso: Análise e Desenvolvimento de Sistemas (ADS)

Este projeto foi desenvolvido como atividade da disciplina de Desenvolvimento Front-End para Web.

## Sobre o projeto

O projeto consiste em um site pessoal chamado fonseca.dev, criado para apresentar um pouco sobre mim, meus estudos, objetivos e interesses.

## Páginas

- index.html - Página principal com apresentação, informações sobre mim, estudos, objetivos, interesses e formulário de contato.
- paginas/interesses.html - Página complementar sobre meus interesses pessoais, como jogos e musculação.

## Recursos utilizados

- HTML
- CSS
- Imagens
- Vídeo
- Links internos e externos
- Tabela
- Formulário demonstrativo

## Como abrir o projeto

Para visualizar o site, basta abrir o arquivo index.html em um navegador ou utilizar a extensão Live Server no Visual Studio Code.

## Testes realizados

Foram testados:

- Links de navegação entre as páginas;
- Links internos das seções;
- Exibição das imagens;
- Reprodução do vídeo;
- Campos do formulário;
- Navegação utilizando a tecla Tab.

## Uso de Inteligência Artificial

Foi utilizada Inteligência Artificial como ferramenta de apoio durante o desenvolvimento, principalmente para tirar dúvidas, revisar o código e auxiliar na organização do projeto.
