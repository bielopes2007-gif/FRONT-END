Alunos iniciam projeto de página pessoal

26 de setembro de 2026 | 10h 23 min

Os estudantes da disciplina de desenvolvimento de front-end iniciaram a criação da página pessoal.

O projeto utiliza títulos, parágrafos, imagens, links de navegação e diferentes elementos semânticos.

Na próxima etapa, os estudantes aplicarão CSS para modificar o layout da página.
